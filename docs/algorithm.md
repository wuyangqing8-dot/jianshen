# Algorithm

三点夹角：u=A−B，v=C−B；acos(clip(u·v/(|u||v|),−1,1))。零长度向量返回 None。
身体直线度使用肩—髋—踝夹角及髋到肩踝直线的距离除以肩踝长度，不使用身体对垂直线的偏角评价平板支撑。
躯干倾斜使用肩髋向量对竖直轴的锐角。当前并不区分向前/向后倾斜。

置信度过滤先于特征计算，缺失值不会当成 0。Python 默认 5 样本坐标滑动平均，也提供 EMA。网页默认使用 3 样本，在姿态推理间隔超过 0.2 秒时使用最近一帧，避免低帧率滞后；网页可观测关键点阈值为 0.28。缺失点清空该点历史；网页容忍约 1.2 秒的短暂姿态丢失。网页多人时继续跟踪模型所选主目标并提示；持续丢失、明显身份跳跃或超过 2 秒的长间隔取消未完成循环。特征函数也可复用通用滤波器，但当前引擎只平滑坐标，避免重复平滑加剧延迟。

状态机：初始必须到达站立/动作起始位并满足网页默认 ≥0.07 秒条件后 armed。进入下降需越过 high−hysteresis；底部需达到 low 并满足持续时间；离开底部需超过 low+hysteresis；返回 high 完成一次。每个条件基于时间而不是固定帧数，网页默认最短完整动作 0.4 秒；低采样率接受实际越过阈值的观测帧。角速度用于静止超时复位，当前未作为所有阶段方向的独立判据。网页超过 2 秒采样间隔重置。持续低速达到动作配置 timeout 时重置，不增加次数。

规则允许上升型动作：将主特征取负后复用同一状态机。开合跳进度=min(左右最小肩角/150, 归一化脚间距/1.5)，手脚必须同时打开。

深蹲未达到底部返回站立不计为完整动作。当前不会为未完成的半程动作生成独立 rep 评分；这类动作需在后续实验中单独标注和统计，不能因为未计数就从误差数据中排除。

自动分组：已有完成动作后，位于起始状态且 12 秒无新完成动作则结束组；手动结束按钮可立即记录。姿态丢失不据此推断训练结束。

平板支撑采用连续评分和有效时长累积；手动结束时生成包含平均/最高/最低姿态分、主要错误、观察时长及质量时长的组记录，并重置下一组计时。训练目标仅提示进度，不改变姿态评分或强制停止。切换动作归档上一动作摘要；训练记录只在本地内存中保留到主动导出或关闭页面。

按动作单独配置迟滞阈值：网页宽松模式膝肘角用4°，开合跳的0–1综合进度用0.05。原先角度单位的5°误用到开合跳会让其无法进入 OPENING，现有端到端模拟点位测试已覆盖此回归风险。半程返回起点显示“不计数”，但不会伪装成一个完成动作给分。
