# Exercise rules and observability

下列角度是网页版“宽松”默认计数阈值；桌面 Python 版仍使用较高的原始阈值，网页可选择“标准”与之对应。“更灵敏”会进一步缩小起止阈值之间的距离，并可能增加误计数。“按我的动作校准”通过当前摄像头观测起止姿势来设置阈值；校准仅在本次网页会话保存，机位变化后需要重做。这些角度不是跨个体通用标准。正式验收需固定视角并调整至受试者可安全完成的动作范围。网页必要关键点短暂缺失会暂停判断、保留未完成循环，持续缺失才会取消；可用维度不足时不会把缺失当作零分。

| 动作 | 起始/终点主特征 | 视角 | 当前实现与限制 |
|---|---|---|---|
| 深蹲 | 膝角 ≥145° / ≤125° | 侧面或45° | 完整周期、深度/躯干/左右差/时长/稳定性；双侧遮挡时不计算左右差 |
| 俯卧撑 | 肘角 ≥145° / ≤115° | 侧面 | 肘角、肩部相对位移、身体对齐及有效侧面髋部方向；无真实胸地距离 |
| 平板支撑 | 静态肩髋踝直线 | 侧面 | 姿态与持续时间分开；头颈线、1.5秒稳定性窗口、70分以上质量时长 |
| 弓步蹲 | 前侧膝角 ≥145° / ≤125° | 清晰侧面 | 优先依据鼻尖朝向与双踝投影区分前侧腿；否则估计弯曲较多的一侧，可能选错；含后腿弯曲 |
| 开合跳 | 综合进度 ≤0.28 / ≥0.67 | 正面 | 双臂与双脚同时张开；显示动作频率（次/分） |
| 臀桥 | 肩髋膝角 ≤140° / ≥158° | 侧面 | 直线度、髋部相对位移、顶端停留与节奏 |
| 卷腹 | 躯干相对水平角 ≤12° / ≥25° | 侧面 | 肩部位移、头颈线与节奏；缺个人基线；无法判断下背贴地 |
| 侧平举 | 上臂肩角 ≤25° / ≥65° | 正面 | 上臂角、肘部伸展、双侧差、躯干摆动；未验证负重 |
| 推举 | 肘角 ≤115° / ≥145° | 正面 | 双侧上臂角、腕部相对高度/双侧差、伸肘与躯干姿态 |

网页版侧别优先沿用上一帧可见侧，明显遮挡时才切换；侧别切换不会立即清空动作进度，但转向或其他人进入画面可能导致误计数。平板/俯卧撑在肩至踝横向投影足够、髋点落在线段范围内时，髋点相对肩踝线的有符号竖直偏移给出“偏低/偏高”二维提示；视角不符时不输出该结论，不能据此诊断脊柱形态。

自动识别先累计至少1.5秒动作特征，只有单一候选动作且稳定0.35秒才确认。相似动作或视角不适合时保持“识别中”；网页识别完成时会回放近期姿态，让已符合完整周期的首次动作计数。人工选择模式可跳过辨认。自动模式尚未用真人标注数据验证分类效果。

九种动作的 `guide` 字段存于 `web/rules.json`，网页“查看当前动作的判定依据”逐一展示机位、起点、另一端、关键关节和完成一次的条件。它们是项目定义的二维几何规则，不是采集真人标准动作并由专家标注的训练数据库。
