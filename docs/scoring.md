# Scoring

每维使用连续区间惩罚 S=max(0,100−k×max(L−x,0,x−U))。总分按可用维度的权重归一化。缺失维度不填 0；所有维度均不可用则不评分。必要特征缺失会在进入评分前暂停。

动态动作在完整循环结束时评分。深度取周期最小角，伸展取最大角；身体对齐取周期最差角。控制取周期时长，躯干稳定性取周期躯干角标准差，后者可能包含正常的动作变化，仍是待验证的简化指标。

错误来自维度得分 <75，最多显示两项低分维度。没有任何专家训练数据，所有分数都是规则分数。不能将 80 分解释为正确率 80%，或将结果当作损伤概率。

平板支撑姿态分数与观察时长独立，质量时长单列。若一侧耳、肩、髋清晰，纳入侧面头颈线指标；疲劳或医学指标未实现。随机森林训练接口仅供后续真实专家标签使用，尚无训练后的模型。

平板和俯卧撑在足够水平的侧面投影下使用肩踝线对应的髋部有符号偏移分别提示偏高或偏低；如果髋点不在投影线段内，相关维度缺失且不参与加权。弓步前腿辨认不可靠时暂停评分。其他动作分别引入肩部位移、上臂角、腕部相对高度、臀桥顶端停留等可观测维度，权重在 core/exercise_rules.py 定义，并同步生成 web/rules.json。
